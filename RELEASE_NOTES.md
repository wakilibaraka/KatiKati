# KatiKati 0.17.0 beta 1

**Unsigned beta.** On first launch, right-click the app and choose Open (macOS will warn because this build is not notarized).

What is new
- Launcher: one app grid with Most Used, Recently Installed and All Apps; scrolls down or sideways; optional trackpad pinch.
- Pinboard: full-screen widget wall or floating panel; Quick Settings switches; system, network, battery and Screen Time cards.
- Configurable shortcuts, including modifier double-taps.
- Works before you grant Accessibility (limited mode); granting it later unlocks the rest.

Known limits
- Accessibility is optional; Bluetooth and Night Shift switches use system APIs that can change between macOS releases.
- New translations are drafts. The full-screen Pinboard, launcher grid and pinch were not exercised on screen before this beta.
- If the pinch gesture opens macOS's own app list too, turn off Launchpad in System Settings > Trackpad > More Gestures.
